# WOCS 특허 모니터링 앱 — 경쟁 서비스 분석

작성일: 2026-04-02

---

## 1. 유사 서비스 비교표

| 서비스 | 가격 | 핵심 기능 | 주요 한계 |
|--------|------|----------|----------|
| **KIPRIS** (키프리스) | 무료 | 국내 특허 검색, 이메일 알림, 키워드 저장 | 알림이 이메일 단방향, 분석 기능 거의 없음, UI 구식 |
| **위즈도메인** (WISDOMAIN) | 무료(기본) / LIGHT·PREMIUM 유료 (문의) | 특허 분석·인용·패밀리트리, 자동보고서 | 가격 비공개 → 중소기업 접근 어려움, 텔레그램·API 연동 없음 |
| **PatSnap** | 연 $수천 (엔터프라이즈) | 글로벌 특허 DB, AI 분석, 실시간 모니터링 | 1인 소기업에 과도한 비용, 한국어 지원 미흡 |
| **Google Patents** | 무료 | 글로벌 특허 무료 검색, 기본 이메일 알림 | 자동화 불가, 분석·시각화 없음, 알림 커스터마이징 제한 |
| **Lens.org** | 무료 (개인/공공기관) / 유료 $1,000~$5,000/년 | 전 세계 특허+논문 통합, 컬렉션·알림 | 한국어 인터페이스 없음, 자동화 연동 불가 |
| **IP-NAVI** (한국발명진흥회) | 무료 (정부 지원) | 중소기업 IP 긴급지원·컨설팅 | 모니터링 자동화 아님, 건별 신청 방식 |
| **ip8.ai** | 유료 (가격 비공개) | AI 기반 연속 모니터링, 노이즈 필터링 | 한국 KIPRIS 연동 없음, 국내 법인 미지원 |

## 2. WOCS 커스텀 앱의 차별점 3가지

### 차별점 1 — 글램핑 제조업 특화 필터링

기존 서비스는 전 산업 범용이다. WOCS 앱은 텐트 구조물·천막·캠핑 관련 KPC 분류코드(IPC: A45F, E04H)만 추적해 불필요한 알림을 90% 이상 제거한다. 경쟁사 3~5곳(출원인명)을 고정 등록하면 그 회사 신규 출원만 즉시 감지한다.

### 차별점 2 — 텔레그램 즉시 알림 + n8n 무코드 자동화

KIPRIS·위즈도메인 모두 이메일 알림만 제공한다. WOCS 앱은 KIPRIS Open API → n8n 워크플로 → 텔레그램 봇으로 신규 출원을 5분 이내 핸드폰에 푸시한다. 1인 사업자가 PC를 켜지 않아도 현장에서 즉시 확인 가능하다.

### 차별점 3 — PDF 선행기술 보고서 원클릭 생성

특허 출원 전 변리사 의뢰 없이 Streamlit 대시보드에서 버튼 하나로 선행기술 조사 PDF를 자동 생성한다. KIPRIS(국내) + Google Patents/SerpAPI(글로벌) 이중 소스를 결합해 보고서에 수록, 비용 절감 효과가 크다.

## 3. 벤치마킹 포인트

### 복사할 기능 (Copy)
- KIPRIS의 키워드 저장 + 이메일 알림 로직 → Telegram으로 채널 변경
- Lens.org의 컬렉션 관리 개념 → 경쟁사별 폴더 구조
- PatSnap의 출원 트렌드 연도별 차트 → Streamlit Plotly로 재현
- Google Patents의 인용 네트워크 시각화 → 핵심 특허 식별에 활용

### 건너뛸 기능 (Skip)
- 특허 가치 금전 평가 (위즈도메인 특화 → 과도한 개발 비용)
- 특허 소송·분쟁 추적 (WOCS 1인 사업 규모에서 불필요)
- 다국어 번역 자동화 (국내 천막 시장 한정이므로 일단 한국어만)
- 논문(학술) 데이터베이스 연동 (Lens.org 기능 → 제조업 실익 낮음)

## 4. 결론: 왜 커스텀 빌드인가

| 기준 | 기존 최적 서비스 | WOCS 커스텀 앱 |
|------|----------------|---------------|
| 월 비용 | 위즈도메인 LIGHT (비공개, 추정 월 수만원) | API 비용만 (KIPRIS 무료 + SerpAPI ~$50/월) |
| 텔레그램 알림 | 없음 | 있음 |
| 글램핑 특화 필터 | 없음 | 있음 |
| 선행기술 PDF 자동화 | 없음 (별도 보고서 구매) | 있음 |
| 기술 스택 재사용성 | 없음 | n8n·Streamlit → 다른 업무에도 확장 가능 |

기존 서비스는 범용 대기업 IP팀용이다. WOCS처럼 특정 기술 분야만 감시하는 1인 제조 사업자에게는 커스텀 경량 앱이 비용 대비 3~5배 효율적이다.
